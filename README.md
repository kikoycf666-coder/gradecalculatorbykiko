# gradecalculatorbykiko
A simple tool for tracking grades and forecasting required scores based on complex syllabus weightings.

## Key Features:
- Syllabus-based Calculation: Input all components of a course (quizzes, labs, exams) with their respective weights to get an accurate current grade.
- Target Score Forecasting: Select your desired final grade (A, A-, etc.), and the tool calculates the average score you need on your remaining assignments/exams to reach it.
- Data Persistence: Uses localStorage to save your course data and grades locally in the browser.
- Cumulative GPA Tracking: A secondary interface to manage and calculate GPA across multiple semesters.

## Why I built this:
Calculating "what I need on the final" is a hassle when a syllabus has dozens of small assignments. This tool replaces manual trial-and-error and repetitive AI prompting with a straightforward input-output interface.
